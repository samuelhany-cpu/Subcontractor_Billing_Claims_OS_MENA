# EXP-002 — Expense Deletion, Restoration, Recycle Bin, and Related Audit Visibility Implementation Notes

## 1. Overview

The EXP-002 vertical slice implements soft deletion, restoration, Recycle Bin query filtering, and transactional audit trail logging for Expenses in the Local Project Expense Tracker.

## 2. Shared Contracts & Scope Boundary

- **OpenAPI Contract Updates**:
  - `POST /api/v1/expenses/{expenseId}/delete` — Soft delete an active expense.
  - `POST /api/v1/expenses/{expenseId}/restore` — Restore a soft-deleted expense.
  - `GET /api/v1/expenses?status=ACTIVE|DELETED|ALL` — Filter expenses by deletion status (default: `ACTIVE`).
- **Domain Types (`@claims-os/domain`)**:
  - `expenseStatuses`: `['ACTIVE', 'DELETED', 'ALL'] as const`.
  - `ExpenseStatusSchema`: Zod enum.
  - `ExpenseListQuerySchema`: includes `status: ExpenseStatusSchema.default('ACTIVE')`.
  - `ExpenseResponse`: includes `deletedAt: string | null`.

## 3. Backend Implementation (`apps/api`)

- **State Transitions & Conflict Guards**:
  - `delete`: rejects if expense non-existent (`404 EXPENSE_NOT_FOUND`), already deleted (`409 EXPENSE_ALREADY_DELETED`), or parent project archived (`409 PROJECT_ARCHIVED`).
  - `restore`: rejects if expense non-existent (`404 EXPENSE_NOT_FOUND`), already active (`409 EXPENSE_ALREADY_ACTIVE`), or parent project archived (`409 PROJECT_ARCHIVED`).
- **Financial Totals Dynamic Updating**:
  - Soft-deleting an expense dynamically removes its amount from Project totals, Payee totals, and Agreement paid calculations (`deletedAt: null` filter).
  - Restoring an expense dynamically returns its amount to all totals.
- **Attachments Preservation**:
  - Soft-deleting an expense preserves attachment database records and private MinIO object storage files. Upload is blocked on soft-deleted expenses. Content streaming endpoint checks expense status.
- **Audit Event Logging**:
  - Executed inside Prisma transactions (`$transaction`).
  - Appends `AuditAction.DELETE` and `AuditAction.RESTORE` with correlation ID and before/after JSON snapshots formatted with exact Decimal strings.

## 4. Frontend Implementation (`apps/web`)

- **Recycle Bin Navigation**:
  - `/expenses?status=DELETED` displays soft-deleted expenses with Arabic `"محذوف"` badge and dashed `.deleted-card` styling.
  - `/expenses` filter form contains `"الحالة"` dropdown (`ACTIVE`, `DELETED`, `ALL`).
- **Expense Detail & Lifecycle Control**:
  - `ExpenseStateControl` component provides inline soft-delete confirmation dialog ("هل أنت تأكد من نقل هذا المصروف إلى سلة المهملات؟") and one-click restore action.
  - Soft-deleted detail page displays soft-delete notice banner and disables edit form and attachment upload form.
