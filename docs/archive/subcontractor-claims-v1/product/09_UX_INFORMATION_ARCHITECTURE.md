## Key screen principles

### Progress grid

- Freeze item code/description columns
- Show previous/current/cumulative side by side
- Inline validation
- Bulk paste from spreadsheets
- Autosave draft
- Filter to changed or incomplete rows

### Payment application review

- Summary cards
- Expandable calculation breakdown
- Validation panel
- Evidence completeness panel
- Version comparison
- Export preview

### Variation detail

- Status and aging header
- Value progression
- Timeline
- Evidence checklist
- Related application/certificate values

## RTL requirements

- Navigation and reading order mirror correctly
- Numeric columns remain logically aligned
- Currency and percentage values remain readable
- Mixed-language text is tested
- Charts and timeline direction are deliberately designed, not automatically flipped
