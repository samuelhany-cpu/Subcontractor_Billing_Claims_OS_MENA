# Definition of Ready and Definition of Done

## Definition of Ready

A story is ready when:

- Business outcome is stated
- Requirement IDs are linked
- Acceptance criteria are testable
- User role and permission are specified
- Tenant and project scope are specified
- Data changes are described
- API impact is described
- Calculation impact is described
- Arabic/English impact is considered
- Out-of-scope behavior is explicit
- Dependencies are resolved

## Definition of Done

- Code implemented within architecture boundaries
- Unit tests pass
- Integration and authorization tests pass where applicable
- Domain calculations have explicit fixtures
- Database migration is reviewed
- API schema is updated
- Audit behavior is implemented
- Arabic and English UI are checked
- Accessibility smoke test completed
- Logs and metrics are sufficient
- Documentation is updated
- Security scan has no unresolved critical finding
- Acceptance criteria are demonstrated
