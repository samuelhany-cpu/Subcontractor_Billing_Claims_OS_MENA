# Pilot Plan

## Pilot customer profile

- Specialist subcontractor
- 5–30 active projects
- At least two quantity surveyors
- Monthly payment applications
- Uses Excel/PDF/email/WhatsApp today
- Has measurable overdue receivables or variation leakage

## Pilot onboarding inputs

- Organization users and roles
- One active project
- Contract summary
- BOQ spreadsheet
- Previous payment application
- Latest certificate
- Open variation register
- Open invoices and payments

## Pilot milestones

1. Import and reconcile project baseline
2. Recreate previous application for validation
3. Produce one live monthly application
4. Record certificate
5. Record invoice and payment
6. Review cash and variation dashboards

## Pilot evidence to collect

- Time spent preparing application before/after
- Number of validation errors
- Revision count
- Missing evidence discovered
- Claimed vs certified difference
- Days to certification and collection
- User activity and satisfaction
- Willingness to pay and renewal intent

## Pilot exit decision

Proceed toward general availability only if:

- At least three organizations complete a live cycle
- At least two pay or sign a paid continuation
- Core calculations reconcile with customer records
- Onboarding effort is economically sustainable
- Users return weekly without intensive prompting
